# 소규모 유역 강우-유출 모의 웹앱 (EPA SWMM + 합리식 검증)

경북 문경시 마성면 모곡리 소규모 유역 4개 지점(D ⊂ C ⊂ B ⊂ A)을 대상으로
**EPA SWMM 5.2**를 웹 서버에서 직접 구동해 강우-유출을 모의하고,
실무 기준인 **합리식** 첨두홍수량과 비교·검증하는 Streamlit 웹앱입니다.

## 주요 기능
| 과제 요구사항 | 구현 |
|---|---|
| ① 모의조건 설정 | 재현기간(2~500년), 강우 시간분포(Huff 3분위/교호블록), 지속기간 또는 임계지속기간 자동탐색, AMC(II/III), 개발 시나리오(불투수 전환율), 조도계수 배율, 하도 단면, 토지이용 면적 편집 |
| ② 모델 실행 | 조건에 맞춰 SWMM 입력파일(.inp)을 생성 → `swmm-toolkit`(EPA 공식 바인딩)으로 실행 → 바이너리 결과(.out) 해석 |
| ③ 결과 시각화 | KPI(첨두유량·첨두시각·총유출량·비유량), 강우-수문곡선, 유역 공간분포 지도(비유량), 지점별 결과표 |
| ④ 시나리오 비교 | 실행 결과 누적 저장, 수문곡선 중첩·첨두유량 막대그래프·조건표 비교 |
| ⑤ 검증 | 재현기간별 합리식 vs SWMM(AMC-III/II, 임계지속기간) 비교 |
| 임계지속기간 | 지속기간별 반복 모의로 첨두유량 최대 지속기간 탐색 |

## 시스템 구성
```
app.py              Streamlit 화면 (조건설정·대시보드·비교·검증)
core/hydro.py       계산엔진: 자료, 합리식, 설계강우, SWMM 입력 생성·실행·결과 해석
data/watersheds.geojson   유역경계·최장유로·출구 (WGS84)
```

## 자료 출처
- 유역면적·토지이용·유로연장·표고: 1:5,000 수치지형도 기반 사용자 구획 및 측량자료
- 확률강우강도식: WAMIS 강우강도식_IDF_General형 (gev, 지역 11, 문경 20051273)
- 강우 시간분포: WAMIS 강우시간분포(Huff) — 지역 11, 3분위, 초과확률 50%
- 유출곡선지수: 홍수량 산정 표준지침(2019) <표 3.1>, AMC-III 설계조건
- 수문학적 토양군: WAMIS 유출곡선지수 자료(2000_낙동강_CN, 낙동강국가3)와 유역경계 중첩

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
